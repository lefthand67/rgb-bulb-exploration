# 🌈 RGB-Чашки: 16 миллионов цветов

Это интерактивная презентация для детей (примерно 9 лет), которая наглядно и просто объясняет, как работает цвет в RGB-лампочках и почему производители заявляют о «16 миллионах цветов».

## 🎯 Цель
После просмотра ребёнок сможет объяснить:
*«В каждой чашке 256 шагов, а если перемножить три чашки — получится 256 × 256 × 256 = 16 777 216»*.

## 🚀 Как запустить (для родителей)

### Способ 1: Быстрый запуск (через терминал)
Если у вас установлен Node.js:
1. Откройте терминал в папке проекта.
2. Выполните команду `npm install`.
3. Выполните команду `npm run dev`.
4. Откройте ссылку `http://localhost:3000` в браузере.

### Способ 2: Готовая версия (Offline)
Если вы хотите запустить презентацию без интернета:
1. Выполните `npm run build`.
2. В папке `dist` появится готовый сайт.
3. Для корректной работы (из-за политик безопасности браузеров с JS-модулями) папку `dist` нужно открыть через простой локальный сервер (например, расширение "Live Server" в VS Code или команду `npx serve dist`).

## 🎮 Управление
* **Слайды:** Стрелки `Вправо` / `Влево` или кнопки на экране.
* **Цветовая лаборатория:**
  * Перетаскивайте уровень «жидкости» в чашках мышкой или пальцем.
  * Используйте стрелки `Вверх` / `Вниз` на клавиатуре, когда чашка выбрана (в фокусе), чтобы менять цвет по одному шагу.
  * Нажмите `Esc`, чтобы снова переключать слайды стрелками.
  * Нажимайте на кнопки-пресеты («Солнце», «Океан» и др.) для мгновенной смены цвета.
